# Xianyu-Notification-to-Bark
🔔 一个简单有效的闲鱼消息监听插件
这个扩展可以**实时监控 Firefox 浏览器中的网页通知**（如闲鱼、网页聊天、客服系统等），   当网页触发系统通知时，扩展会**自动将通知内容转发到 Bark 推送服务**，实现**手机实时提醒**。


# 🔔 Firefox Notification → Bark 推送扩展

> **功能简介**  
> 本扩展可以拦截 Firefox 浏览器网页的通知（Notification API），  
> 并将通知内容通过 **Bark** 推送到你的手机，实现 **实时消息提醒**。  
>  
> 适用于：闲鱼网页版、在线客服、网页聊天系统、订单系统等任意支持通知的网站。

---

## ✨ 功能特性

- 🚀 实时捕获网页的通知消息
- 📱 自动转发到 Bark App（iOS / Android 均支持）
- 🧩 支持域名白名单过滤
- 🔁 去重与速率限制机制，防止重复推送
- 💾 本地保存配置，重启浏览器后仍然生效
- ⚙️ 网络异常自动重试，可靠稳定

---

## 📦 安装步骤

1. 下载本项目：
   ```bash
   git clone https://github.com/yourname/firefox-notify-bark.git
2. 打开 Firefox，输入：
   about:debugging#/runtime/this-firefox
3. 点击 “临时加载附加组件”：
4. 扩展加载成功后，浏览器右上角会出现一个扩展图标（铃铛图标）。

⚙️ **使用方法**

点击浏览器右上角的扩展图标，打开设置页面；

在 Bark Key 输入框中填入你的 Bark 推送 Key；

例如你的 Bark 地址是 https://api.day.app/abcdef123456/

只需要填写 abcdef123456 部分即可；

可选设置：

**域名白名单**：仅转发来自这些域名的通知（每行一个）；

**去重窗口（毫秒）**：防止重复通知；

**速率限制**：每分钟最多推送次数；

**重试间隔 与 最大重试次数**：网络不稳定时自动重发；

点击 保存设置。

完成后，只要网页触发系统通知（如闲鱼消息、客服提醒等），

扩展就会自动将消息通过 Bark 推送到手机端。
